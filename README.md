# STEM CodeQuest (极客多巴胺营地)

专为 iPad 横屏打造的 STEM / CS 闯关式学习 PWA 应用，设计风格融合**多巴胺极客配色**与**高确定性/结构化交互**，对小学生及阿斯伯格/神经多样性儿童高度友好。

---

## 🌟 核心特性

1. **PWA 离线支持 (Offline First)**
   - 基于 `vite-plugin-pwa` 与 Workbox，所有页面、逻辑、SVG 资源均已预缓存（Precached）。
   - 音频采用 **Web Audio API 纯代码实时物理合成**，完全脱机运行，零音频网络请求与延迟。
   - 学习进度（XP、连胜天数、生命能量、通关节点）持久化保存在本地 `localStorage`。

2. **iPad 横屏专属交互**
   - 锁定/优先考虑横屏体验（`orientation: landscape`）。
   - 左右分屏布局：左侧交互答题/积木拖放，右侧实时 Scratch 仿真舞台（支持小猫坐标移动、漫画气泡说话、绿旗/红灯运行测试）。
   - 3D 触觉质感按钮（Chunky dopamine buttons），按压下沉与微震音效反馈。

3. **Duolingo 式层级体系**
   - **模块 (Module)**：当前为 `Scratch 积木王国`（预留 Python 终端、硬件机器人）。
   - **部份 (Section)**：第 1 部份「动起来与第一条指令」、第 2 部份「循环循环再循环」等。
   - **单元 (Unit)**：第 1 单元「绿旗与第一次移动」已完全开放，包含 4 个精心编排的关卡。
   - **节点 (Node)**：
     1. `启动魔法`：认识起跑帽与绿旗触发机制。
     2. `迈出第一步`：积木拼装（当绿旗被点击 -> 移动 10 步）。
     3. `数值与距离`：参数调节与相反数/负数概念探索。
     4. `小猫亮相`：综合挑战，小猫移动并在舞台打招呼。

4. **极客多巴胺 + 友善无冗余**
   - 语言极其精简，去除非必要废话，单句直击规则与目标。
   - 赛博深色底色搭配高对比荧光青、糖果黄与亮粉，减少视觉疲劳，激发探索多巴胺。

---

## 🚀 启动与构建

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产环境打包
npm run build

# 本地预览 PWA 生产包
npm run preview
```
