# STEM CodeQuest (极客多巴胺营地)

专为 iPad 横屏打造的 STEM / CS 闯关式学习 PWA 应用，设计风格融合**多巴胺极客配色**与**高确定性/结构化交互**，对小学生及阿斯伯格/神经多样性儿童高度友好。

---

## 🌟 核心特性

1. **PWA 离线支持 (Offline First)**
   - 基于 `vite-plugin-pwa` 与 Workbox，所有页面、代码、SVG 资源均已预缓存（Precached）。
   - 音频采用 **Web Audio API 纯代码实时物理合成**，完全脱机运行，零音频网络请求与延迟。
   - 学习进度（XP、连胜天数、生命能量、通关节点）持久化保存在本地 `localStorage`。

2. **iPad 横屏专属交互 (Light Mode)**
   - 锁定/优先考虑横屏体验（`orientation: landscape`）。
   - 清新明亮 Light Mode 风格（`#F8FAFC` 柔和底色搭配高饱和多巴胺点缀），护眼且符合视觉认知。
   - 3D 触觉质感按钮（Chunky dopamine buttons），按压下沉与微震音效反馈。

3. **双轨学习体验：平板导航 + 电脑动手实操**
   - 学生通过 iPad 闯关学习逻辑、预测代码、拼装蓝图，并按照指示在电脑 Scratch 3.0 独立完成项目。
   - **Scratch 官方双语积木渲染引擎**：支持帽子积木、堆叠积木、C 型循环/分支积木、E 型 `if-else` 双分支积木、平底 Cap 终结积木、白底数值气泡、橙色变量药丸、绿色嵌套运算胶囊、深色下拉胶囊以及支持比较运算的六边形布尔侦测插槽。

4. **DK 精选项目 · Scratch 3.0 实战课程体系**
   - **第 1 单元：星星猎手 (Star Hunter · 5 关)**
     - **关卡 1–4**：鼠标操控小猫、海底背景与气泡音效、章鱼巡逻怪（碰壁反弹与左右翻转）、碰撞与游戏结束。
     - **关卡 5 · 单元综合大挑战**：专注模式（隐藏右侧代码工作台），概念本质辨析 + 全新太空/幽灵情境独立实战迁移。
   - **第 2 单元：星星猎手 2 (Star Hunter 2 · 4 关)**
     - 敌人的大小/方向/速度调优、复制多敌人、采集随机闪现的星星、建立 `Score` 变量计分器。
   - **第 3 单元：追逐奶酪 (Chase the Cheese · 11 关)**
     - **核心玩法**：键盘四向操控 Mimi、手绘芝士与得分音效、幽灵双引擎并发出没（追踪 + 随机瞬移）、舞台背景音乐循环。
     - **迷宫与物理**：手绘迷宫角色居中锁定、开局初始化与深色背景打磨、修剪尾巴与碰壁退步防穿墙物理阻挡。
     - **AI 巡逻与终局闭环**：甲虫 50/50 随机 90° 避障巡逻（`if-else`）、碰撞广播 `GG` 精准停用键盘、`Score > Highest` 持久最高分纪录、以及 `Game Over` 图层置顶居中弹窗。

5. **命令行极客 · 第 1 单元：文件系统 (File System)**
   - **关卡 1 · 穿梭文件世界**：理解目录（Directory）房间概念，掌握 `pwd`、`ls`、`cd <dir>` 与 `cd ..`。
   - **关卡 2 · 打造与修改房间**：创建专属目录 `mkdir`、重命名房间 `mv`、拆除空房 `rmdir`。
   - **关卡 3 · Vim 写作与 cat 查看**：极简模式切换（`i` 动笔与 `Esc` 盖笔盖）、`:wq` 保存退出，以及 `cat` 快速打印文件内容。
   - **关卡 4 · 文件系统大通关 (综合复习)**：专注模式（隐藏右侧代码），学生在电脑终端独立构建特工基地并完成全套实战任务。
   - **专属终端看板**：内置 macOS 风格交互式终端视窗与命令雷达速查表。

6. **极客多巴胺 + 友善无冗余**
   - 语言极其精简，去除非必要废话，单句直击规则与目标。
   - 内置**隐藏开发者工具**（连续轻触 5 次左上角 CQ 图标），支持一键清空进度、解锁关卡、直通指定 node。

## 🚀 启动与构建

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产环境打包
npm run build

# 本地预览 PWA 生产包
npm run preview
```
